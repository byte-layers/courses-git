À la fin de ce cours, vous savez protéger la branche principale d'un projet, proposer un changement par une merge request, le relire, le fusionner, et résoudre un conflit.

## Pour qui ?

Ce cours s'adresse aux personnes qui savent créer un projet GitLab et utiliser les branches, ce qu'enseignent [Créer son premier projet GitLab](https://byte-layers.com/fr/labs/gitlab-first-project) et [Travailler en parallèle avec les branches](https://byte-layers.com/fr/skills/git-branches-merge). Pour résoudre un conflit, il faut savoir lire ses marqueurs.

## Comment ça se passe

Cinq étapes, environ une heure. Vous travaillez sur un projet GitLab public, `statuspage-mr`, et dans le dossier `~/layers-git/gitlab-mr`. un compte gratuit sur [gitlab.com](https://gitlab.com/) et Git. Les vérifications utilisent `curl`, livré avec Git Bash sous Windows.

**Sous Windows**, tapez les commandes dans le terminal **Git Bash**, livré avec Git.
