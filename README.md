# courses-git

Les contenus du cluster Git de byte_layers : stacks `git`, puis `gitlab` et `gitlab-ci`. Un dossier par contenu, à plat.

Le parcours de chaque stack est décrit dans `stacks/<stack>/stack.yml`. Les fichiers de l'apprenant vont dans `~/layers-git/`, et chaque contenu ne touche qu'à son propre sous-dossier.

Prérequis : un terminal (Git Bash sous Windows) et Git 2.28 ou plus récent.

Les animations GIF se régénèrent avec `tools/make_gifs.py`, qui demande Pillow et écrit dans le dossier `.layers/assets` de chaque contenu.
