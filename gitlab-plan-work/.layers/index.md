Dans ce lab, vous préparez le travail d'une équipe sur un projet GitLab : des labels pour classer, un jalon pour la date cible, des issues pour les tâches, un tableau pour le suivi, et un wiki pour la documentation.

**Niveau** : savoir créer un projet sur GitLab, ce qu'enseigne [Créer son premier projet GitLab](https://byte-layers.com/fr/labs/gitlab-first-project). un compte gratuit sur [gitlab.com](https://gitlab.com/) et Git. Les vérifications utilisent `curl`, livré avec Git Bash sous Windows.

**Vos fichiers** se limitent à `~/byte-layers/git/gitlab-plan/url`, qui garde l'adresse du projet. Tout le reste se fait dans l'interface de GitLab, et le projet doit être **public** pendant le lab.

> 💡 **Remarque.** Les récentes versions de GitLab regroupent les issues sous le nom **Work items**. Une issue en est le type le plus courant.
